# 업무 보드 — 4인 자석 보드

로그인 없는 한 장짜리 업무 게시판입니다. 네 사람의 칸과 공통 업무 칸이 있고,
메모 왼쪽 끝의 색 점(**자석**)을 잡아 이름 칸이나 공통 업무로 끌어다 붙입니다.
디자인은 애플 스타일(시스템 서체·흰 카드·iOS 시스템 색·반투명 상단바)이며 다크 모드를 따릅니다.

- 이름 오른쪽 **+** → 그 사람 칸 맨 위에 새 메모 (Enter 저장 · Shift+Enter 줄바꿈 · Esc 취소)
- 자석 끌기 → 원하는 칸·위치에 착 붙음 (마우스·터치 모두)
- 키보드: 자석에 초점 → ←/→ 다른 칸으로, ↑/↓ 칸 안 순서
- 메모 글자 누르기 → 고치기 · ✓ 완료 · ✕ 떼기(되돌리기 가능) · 「완료 치우기」
- 이름 누르기 → 이름 바꾸기

## 팀 공유

보드는 Vercel 함수 `api/board.js` + **Upstash Redis** 로 팀 전체가 함께 씁니다.

1. Vercel 대시보드 → 이 프로젝트 → **Storage**(또는 Integrations → Marketplace) → **Upstash for Redis** → 무료 DB 만들기 → 이 프로젝트에 연결
   (환경변수 `KV_REST_API_URL`·`KV_REST_API_TOKEN` 또는 `UPSTASH_REDIS_REST_URL`·`UPSTASH_REDIS_REST_TOKEN` 이 자동으로 들어갑니다)
2. **Redeploy** — 상단에 초록 점과 「팀과 공유 중」이 뜨면 연결된 것입니다.
3. (선택) 환경변수 `BOARD_KEY` 를 넣으면 키 없는 접근을 막습니다. 팀에는 `https://<주소>/#k=<키>` 로 한 번 열어 주면 기억합니다.

동작:
- 바꾼 내용은 화면에 바로 반영되고 서버에 순서대로 저장됩니다. 동시에 두 사람이 바꾸면 버전 비교로 충돌을 잡아,
  최신 보드 위에 내 변경을 다시 적용합니다(덮어쓰지 않음).
- 다른 사람의 변경은 10초마다, 그리고 탭으로 돌아올 때 바로 받아 옵니다.
- 연결이 끊기면 「오프라인 · 저장 대기」로 모아 두었다가 다시 연결되면 보냅니다.
- 저장소가 연결되지 않았으면 「이 기기에만 저장」으로 표시되고 브라우저(localStorage)에만 저장됩니다.
  처음 연결될 때 공유 보드가 비어 있으면, 먼저 연결한 사람의 기존 보드가 공유 보드의 시작점이 됩니다.

## 구조

빌드 없는 정적 사이트 — Vercel 에 그대로 올라갑니다.

```
index.html        뼈대
css/board.css     애플 스타일 디자인 (라이트·다크)
js/store.js       상태 로직 (순수 함수, 테스트 대상)
js/sync.js        팀 공유 동기화 (대기 중인 변경 · 충돌 시 재적용 · 폴링)
js/app.js         그리기·자석 끌기·편집·키보드 이동
api/board.js      Vercel 함수 (GET/PUT)
lib/shared-board.js  저장 로직 (버전 비교 저장, Upstash REST)
tests/            node --test tests/
```

로컬 미리보기: `python -m http.server 8000` 후 http://127.0.0.1:8000
