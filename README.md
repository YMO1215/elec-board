# 업무 보드 — 4인 자석 보드

로그인 없는 한 장짜리 업무 게시판입니다. 네 사람의 칸과 공통 업무 칸이 있고,
메모 왼쪽의 그립(⠿ 모양 핸들)을 잡아 이름 칸이나 공통 업무로 끌어다 붙입니다. 폰에서는 메모의 「이동」 버튼으로도 옮깁니다.
디자인은 iOS 규칙을 따릅니다 — 시스템 서체, 뉴트럴 레인, 담당자 색은 아바타와 카드 옆 얇은 바에만, 상단바·토스트에만 유리 재질, 라이트·다크 자동.

- 이름 오른쪽 **+** → 그 사람 칸 맨 위에 새 메모 (Enter 저장 · Shift+Enter 줄바꿈 · Esc 취소)
- 그립 끌기 → 원하는 칸·위치에 착 붙음 (마우스·터치 모두). 누르면 살짝 눌리고, 드는 동안에만 그림자, 놓으면 0.35초 스냅
- **이동 버튼(⇄)** → 담당자 4명 + 공통을 큰 행으로 보여 주는 시트에서 탭 한 번으로 이동 (드래그가 어려운 터치용)
- 키보드: 자석에 초점 → ←/→ 다른 칸으로, ↑/↓ 칸 안 순서
- 메모 글자 누르기 → 고치기 · ✕ 떼기(되돌리기 가능)
- **체크 버튼** → 카드가 보드에서 바로 사라지고(개수도 줄어듦) 「완료」 탭에서 담당자별로 보임. 알림의 「되돌리기」로 즉시 복구
- 상단 세그먼트 **진행 중 / 완료** → 완료를 누르면 보드 대신 담당자별 완료 목록(완료한 날짜 포함). 「되돌리기」로 다시 진행 중, 삭제 버튼으로 삭제. 브라우저 뒤로 가기로도 보드로 돌아옴
- 폰(620px 이하)은 1열 세로 스택이고 담당자 칸마다 접기 버튼이 있음(접힘은 세션 중 메모리만)
- **공통 업무 메모 오른쪽의 화살표(⌄)** → 누르면 담당자 4명의 색 원 + 각자의 입력줄이 열림. 글은 자동 저장되고 팀과 공유됨(Enter 로 끝내기, Esc 로 취소). 닫혀 있을 땐 글이 있는 사람의 색 점이 화살표 옆에 표시됨
- 이름 누르기 → 이름 바꾸기
- **맨 위 날짜** 누르기 → 달력. 3조 2교대(주주야야비비)를 담당자 색으로 날짜마다 표시(주=진한 색, 야=진한 색+테두리, 비=옅은 색+테두리). 날짜를 누르면 그날 세 사람의 근무가 아래에 나옴

### 교대 기준

`js/shift.js` — 2026-10-01: 담당자1 야간, 담당자2 비번, 담당자3 주간. 세 조는 2일씩 어긋나 돕니다.
10/1 은 각 블록의 **둘째 날**입니다(담당자1: 9/28 주간 시작 → 28·29 주간, 30·1일 야간). 그래서 기준 위치 `ANCHOR` 는
`2026-09-30` 입니다. 담당자4는 교대 대상이 아니라 표시하지 않습니다.

## 팀 공유

보드는 Vercel 함수 `api/board.js` + **Upstash Redis** 로 팀 전체가 함께 씁니다.

1. Vercel 대시보드 → 이 프로젝트 → **Storage**(또는 Integrations → Marketplace) → **Upstash for Redis** → 무료 DB 만들기 → 이 프로젝트에 연결
   (환경변수 `KV_REST_API_URL`·`KV_REST_API_TOKEN` 또는 `UPSTASH_REDIS_REST_URL`·`UPSTASH_REDIS_REST_TOKEN` 이 자동으로 들어갑니다)
2. **Redeploy** — 상단에 초록 점과 「팀과 공유 중」이 뜨면 연결된 것입니다.
3. (선택) 환경변수 `BOARD_KEY` 를 넣으면 키 없는 접근을 막습니다. 팀에는 `https://<주소>/#k=<키>` 로 한 번 열어 주면 기억합니다.

동작:
- 바꾼 내용은 화면에 바로 반영되고 서버에 순서대로 저장됩니다. 동시에 두 사람이 바꾸면 버전 비교로 충돌을 잡아,
  최신 보드 위에 내 변경을 다시 적용합니다(덮어쓰지 않음).
- 다른 사람의 변경은 10초마다, 그리고 탭으로 돌아올 때 바로 받아 옵니다.
- 연결이 끊기면 「오프라인 · 저장 대기」로 모아 두었다가 다시 연결되면 보냅니다.
- 저장소가 연결되지 않았으면 「이 기기에만 저장」으로 표시되고 브라우저(localStorage)에만 저장됩니다.
  처음 연결될 때 공유 보드가 비어 있으면, 먼저 연결한 사람의 기존 보드가 공유 보드의 시작점이 됩니다.

## 구조

빌드 없는 정적 사이트 — Vercel 에 그대로 올라갑니다.

```
index.html        뼈대
css/board.css     iOS 디자인 토큰 + 컴포넌트 (라이트·다크)
js/store.js       상태 로직 (순수 함수, 테스트 대상)
js/shift.js       3조 2교대 계산·월 달력 격자 (순수 함수, 테스트 대상)
js/calendar.js    달력 창
js/dom.js         요소 만들기 도우미
js/icons.js       SVG 아이콘 세트 (stroke 2, 둥근 캡)
js/avatar.js      아바타 이니셜 (순수 함수, 테스트 대상)
js/sync.js        팀 공유 동기화 (대기 중인 변경 · 충돌 시 재적용 · 폴링)
js/app.js         그리기·자석 끌기·편집·키보드 이동
api/board.js      Vercel 함수 (GET/PUT)
lib/shared-board.js  저장 로직 (버전 비교 저장, Upstash REST)
tests/            node --test tests/
```

로컬 미리보기: `python -m http.server 8000` 후 http://127.0.0.1:8000
